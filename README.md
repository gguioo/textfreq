# textfreq · 文科文本批量词频统计工具箱

把几百上千个知网导出的 TXT 文献一次性丢进文件夹，一条命令出结果：
**词频总表 · 年度趋势 · 共词矩阵 · 搭配表 · 词汇多样性 · 关键词**，全部是规范 CSV 数据表，可直接进 Excel 做统计。

本工具只出数据，不含任何画图功能。

## 为什么是这个工具

手写 Python 脚本做文献词频统计，要处理编码、页眉页脚、分词、停用词、共现矩阵一长串琐碎规范。
textfreq 把这些全部打包：

- **批量读取**：自动识别 UTF-8 / GBK / GB18030 / UTF-16 编码
- **自动清洗**：去页码、页眉页脚、下载站水印、网址等常见文献噪音
- **中文分词**：jieba 分词，支持自定义领域词表（专有名词整词识别）
- **停用词内置**：自带中文停用词表，可追加自己的黑名单
- **六类统计**：词频总表（含分布度 D）、年度趋势（含每万词标准化频率）、共词矩阵、搭配强度（MI / t）、词汇丰富度、关键词对数似然检验

## 安装

```bash
pip install git+https://github.com/gguioo/textfreq.git
```

Windows 用户：先装 [Python 3.8+](https://www.python.org/downloads/)（安装时勾选 "Add Python to PATH"），然后打开「命令提示符」粘贴上面那行安装命令即可。

## 用法

```bash
# 最简单：整批 TXT 跑完整统计，输出到 textfreq_out/
textfreq run 知网导出文件夹

# 常用选项
textfreq run 知网导出文件夹 \
  -o 结果目录 \
  --top 200 \                       # 词频总表收录前 200 词
  --cooc-top 50 \                   # 共词矩阵取前 50 高频词
  --stopwords 我的停用词.txt \       # 追加停用词（如：俄罗斯）
  --userdict 领域词表.txt            # 领域词表（如：十月革命、彼得堡）

# 关键词检验：另给一批参照语料（例如全部知网论文文件夹），
# 本批相对参照语料显著偏高的词即"本批关键词"
textfreq run 本批文献文件夹 --reference 参照语料文件夹
```

## 输出说明

| 文件 | 内容 |
|------|------|
| `词频总表.csv` | 全语料词频排名（默认前 100），附带该词的跨文档分布度 D（越接近 1 越均匀分布在各篇文献中） |
| `年度趋势.csv` | 文件名含年份（如 `2010.txt`）时按年份 × 词语计数；每年附总词数，以及"每万词频率"标准化列（消除各年份语料量差异后可直接横向比较） |
| `共词矩阵.csv` | 前 N 高频词的文档级共现次数 |
| `搭配表.csv` | 高频词之间在句内窗口的搭配强度：互信息 MI 值越大搭配越"专"，t 分数越大越"确信"（详见下表筛选） |
| `词汇多样性.csv` | 每篇文献与全语料的丰富度指标：TTR、STTR、Guiraud 指数、奇次词占比 |
| `关键词.csv` | 需 `--reference`；本批语料相对参照语料的对数似然（LL）检验，LL 越大越显著，按显著性排序 |

## 指标速查

- **分布度 D（Juilland）**：一个词是"贯穿全批"还是"只在少数几篇扎堆"，1 为均匀分布。
- **每万词频率**：年度趋势里的标准化列，语料量不均也能比较年份。
- **MI（互信息）**：搭配专指度；t 分数：搭配可信度。实务上可先按 t 降序、再看 MI ≥ 3 的行。
- **关键词 LL（对数似然）**：语料库语言学通用的显著性检验，比单纯比词频大小更严谨。

## 文件命名建议

希望得到年度趋势时，把年份写进文件名，例如：
`中俄关系述评_2008.txt`、`俄罗斯远东政策_2015.txt`。
没有年份也能跑，只是跳过趋势表。
